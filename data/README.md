# data/

```
data/raw/
  accelerometer/<sow>.csv          # timestamp, Acc            (1-minute resolution)
  video/<sow>_activity.csv         # Timestamp, Flow_totals    (sub-minute resolution)
  meta/<sow>.csv                   # farrowing onset, crate times, pen type, ...
```

See the top-level [README](../README.md#data-layout) for the exact
column names each file needs.

## `sample_sow`

The three `sample_sow` files already here are **fully synthetic**,
generated by [`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py) —
not a real animal. They exist purely so the pipeline is runnable
immediately after cloning this repo, without needing any real data.
Regenerate them (or inspect exactly how they're built) with:

```
python scripts/generate_sample_data.py
```

## Real data

The real raw sensor data behind this code is not published in this
repository, for privacy. A preprocessed, anonymized training dataset
derived from it — the per-instance feature tables actually used for
model training, with real sow identifiers replaced by sequential
integers — is published separately; see the top-level README or the
project's data release for where to get it.

To run this pipeline on your own data, drop matching
`accelerometer/<sow>.csv`, `video/<sow>_activity.csv` and `meta/<sow>.csv`
files into the three folders above, using any id you like in place of
`<sow>`.
